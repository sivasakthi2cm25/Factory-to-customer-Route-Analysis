
# Factory-to-Customer Shipping Route Efficiency Analysis
## 1. Project Overview
This project focuses on analyzing and optimizing the shipping routes from Nassau Candy's manufacturing facilities and distribution centers to customer locations.

The primary objective is to reduce transportation costs, minimize delivery distances, improve vehicle utilization, and increase on-time delivery performance.

## 2. Project Objectives
Analyze existing factory-to-warehouse shipping routes.
Evaluate warehouse-to-customer delivery routes.
Identify inefficient shipping routes.
Optimize delivery routes and transportation schedules.
Reduce fuel consumption and transportation costs.
Improve truck capacity utilization.
Minimize delivery lead times.
Improve overall supply chain efficiency.

## 3. Scope of the Project
The project covers:
Factory locations.
Distribution center locations.
Customer delivery locations.
Transportation routes.
Shipment volumes.
Vehicle capacity.
Delivery schedules.
Transportation costs.

## 4. Key Performance Indicators (KPIs)
Total Transportation Cost
Cost Per Shipment
Total Distance Travelled
Average Delivery Time
On-Time Delivery Percentage
Vehicle Utilization Rate
Fuel Consumption
Empty Mileage Percentage
Order Fulfillment Rate

## 5. Methodology
Collect shipment and transportation data.
Identify factory, warehouse, and customer locations.
Analyze existing transportation routes.
Calculate transportation costs and delivery distances.
Identify inefficient routes and underutilized vehicles.
Apply route optimization techniques.
Compare existing routes with optimized routes.
Estimate potential cost and time savings.

Power BI – Interactive dashboards and visualization.

## 9. Conclusion
This project aims to develop a more efficient and cost-effective distribution network for Nassau Candy Distributors through transportation data analysis, geographical visualization, and route optimization techniques.

The proposed improvements will support better logistics planning, lower operating expenses, and improved customer satisfaction.
